📮 SMTP 伺服器設定（用於透過中繼服務寄送）

⚠️ 瀏覽器無法直接連 SMTP 伺服器，需要您自行架設一個小型 HTTP→SMTP 中繼服務（範例見下方），把上面的 URL 填入。
若不想架設中繼服務，可改用「💾 下載 .eml」由您本機的 Outlook / Apple Mail / Thunderbird 直接寄送。
SMTP 帳號密碼僅儲存在您本機的 localStorage（明文），請評估安全性後使用。

📋 範例：簡易 SMTP 中繼服務（Python Flask，~30 行） 
# pip install flask flask-cors
from flask import Flask, request, jsonify
from flask_cors import CORS
import smtplib, ssl, base64
from email.message import EmailMessage

app = Flask(__name__); CORS(app)

@app.post('/send')
def send():
    p = request.get_json()
    msg = EmailMessage()
    msg['From'] = f"{p['from']['name']} <{p['from']['email']}>"
    msg['To'] = ', '.join(p['to'])
    if p.get('cc'): msg['Cc'] = ', '.join(p['cc'])
    msg['Subject'] = p['subject']
    msg.set_content('請以 HTML 方式檢視此信件')
    msg.add_alternative(p['html'], subtype='html')
    for a in p.get('attachments', []):
        msg.add_attachment(base64.b64decode(a['content']),
            maintype='application', subtype='octet-stream',
            filename=a['filename'])
    s = p['smtp']
    recipients = list(p['to']) + list(p.get('cc', [])) + list(p.get('bcc', []))
    if s['secure'] == 'ssl':
        srv = smtplib.SMTP_SSL(s['host'], s['port'], context=ssl.create_default_context())
    else:
        srv = smtplib.SMTP(s['host'], s['port'])
        if s['secure'] == 'starttls':
            srv.starttls(context=ssl.create_default_context())
    if s.get('user'): srv.login(s['user'], s['pass'])
    srv.send_message(msg, to_addrs=recipients); srv.quit()
    return jsonify(ok=True)

if __name__ == '__main__':
    app.run(host='127.0.0.1', port=8081)
